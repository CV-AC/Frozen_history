# Contributing

Use Python 3.12, install `requirements-dev.txt`, and run `python -m pytest -q` before submitting changes. Tests create synthetic data in temporary directories and do not require dataset access.

Keep geometry conventions, sequence resets and metric aggregation explicit when changing experimental behavior. Record dependencies, configurations and dataset revisions with reported results. Do not submit checkpoints, dataset samples, private paths, credentials or personal metadata to this anonymous source repository.

The project keeps method explanations in documentation and intentionally distributes Python without comments or docstrings. Keep this convention when editing source. New third-party files must retain their legally required notices and be documented separately.
